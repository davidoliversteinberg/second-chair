# Screenshot provenance

## Current — 0.3.4

The `*-0.3.4.jpg` images were captured on October 14, 2026 from the 0.3.4 production
frontend in isolated local demo mode. The fixture extends the four-item demo to 50 fictional
findings for pagination and density testing. It includes one tracked request, a reported user
reply, a private note, and a scripted agent conversation. No company content or live model calls
were used. Captures are unmodified browser JPEGs.

All compact captures are 548 × 868: inbox, thread, thread-chat (scrolled history), detail
(actionable thread), chat, history, health, and usage. The expanded desk is 1440 × 1000.
Counts change as a finding is opened. This fixture is illustrative, not the default four-item demo.
The README/app guide use this set; earlier sets below are historical.
