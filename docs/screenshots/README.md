# Screenshot provenance

The `*-0.3.3.jpg` images are current documentation captures made on October 14, 2026 from the
0.3.3 production frontend, served locally in demo mode with an isolated temporary data directory.
The fixture contains eight fictional findings and three scripted conversations. No company data
or live model calls were used. The fixture is illustrative; it is not the default three-item demo.
